# Product Requirement Document (PRD)
**Project:** Synthetic Intelligence Portfolio & Interactive Engineering Lab (Ardi Yustiar)

---

### 1. Ringkasan Proyek
Membangun platform portofolio dan laboratorium rekayasa digital berskala profesional untuk Ardi Yustiar bertajuk "The Bridge"—menghubungkan keahlian Rekayasa Antarmuka Frontend dengan implementasi Kecerdasan Buatan (AI/ML) serta Backend Architecture. Mengusung estetika Cyber-Terminal Futuristic Minimalist yang bersih, responsif, dan berorientasi masa depan.

---

### 2. Fitur Utama & Spesifikasi Kartu Proyek Interaktif
Kartu etalase proyek menyajikan dua tombol aksi utama untuk memberikan pengalaman teknis yang utuh kepada pengunjung:

#### Fitur Live Preview (Dynamic Interactive Sandbox & AI Playground):
*   **Modus UI Component:** Menyediakan area uji coba komponen antarmuka tempat pengunjung dapat mengubah presets varian, warna tema, dan tingkat transparansi kaca secara langsung.
*   **Modus AI/ML Model:** Menyediakan panel simulasi inferensi tempat pengunjung dapat memasukkan sampel input, menggeser parameter ambang batas (confidence & temperature), memicu proses inferensi, dan melihat hasil keluaran data terformat.

#### Fitur System Specs (Engineering Specs & API Contract Inspector):
*   **Diagram Alur Arsitektur:** Menampilkan visualisasi rantai aliran data dari antarmuka frontend, REST API backend, hingga basis data cloud.
*   **Spesifikasi Endpoint API:** Menampilkan metode HTTP dan jalur endpoint API yang digunakan.
*   **Viewer Skema Data:** Menyajikan struktur request dan response JSON interaktif lengkap dengan penanda status dan fitur salin data.
*   **Metrik Rekayasa:** Menampilkan indikator performa utama seperti tingkat akurasi model, latensi respons, dan throughput.

---

### 3. Navigasi Ekosistem & Kenyamanan Pengguna

*   **Sistem Navigasi Ganda:** Navigasi Atas untuk perpindahan rute utama aplikasi, serta Sidebar Samping untuk navigasi jangkar ke bagian-bagian halaman aktif.
*   **Optimalisasi Layar Seluler:** Seluruh komponen modal, terminal, dan grid kartu teroptimasi secara responsif sehingga nyaman digunakan pada perangkat desktop, tablet, maupun smartphone.
*   **Manajemen Data Terpisah:** Seluruh konten proyek, riwayat karier, dan spesifikasi teknik terisolasi dalam berkas data terstruktur untuk memudahkan pemeliharaan tanpa merusak komponen antarmuka.
